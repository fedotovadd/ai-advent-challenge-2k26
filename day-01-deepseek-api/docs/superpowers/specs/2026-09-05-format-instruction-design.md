# Инструкция свободного формата — дизайн

## Цель

Разделить базовый system prompt и управление форматом ответа. Для обычного текста пользователь может задать дополнительную инструкцию формата; для JSON приложение использует только API-параметр `response_format` и не добавляет автоматическую системную инструкцию.

## Интерфейс

Правая панель сохраняет существующее поле **System prompt** как базовую инструкцию текущей сессии.

- При выборе **Обычный текст** под выбором формата показывается поле **Инструкция свободного формата**. Оно необязательно и может быть пустым.
- При выборе **JSON** это поле скрыто. Система не добавляет текст `Верни только валидный JSON без Markdown-разметки.` и не показывает заменяющий его prompt.
- Значение инструкции сохраняется в настройках сессии, даже когда пользователь временно переключается в JSON; при возврате к обычному тексту оно восстанавливается.

## Данные и API

В объекте настроек сессии появляется строка `formatInstruction`, по умолчанию пустая. `PUT /api/sessions/{sessionId}/settings` принимает её вместе с текущими полями; строка может быть пустой и обрезается при сохранении.

При создании запроса:

- текстовый формат: фактический system prompt равен базовому system prompt либо базовому prompt, за которым через пустую строку добавлена непустая `formatInstruction`;
- JSON: фактический system prompt равен только базовому system prompt, а SDK получает `response_format={"type": "json_object"}`;
- прежняя автоматическая JSON-инструкция удаляется полностью.

Метаданные продолжают показывать фактический system prompt и итоговый payload.

## Ошибки и проверки

- `formatInstruction` должен быть строкой; пустая строка валидна.
- Неверный тип возвращает 400 без изменения сохранённых настроек.
- Тесты проверяют сохранение пустой инструкции, добавление инструкции для обычного текста, её отсутствие в JSON-режиме, наличие `response_format` в JSON и наличие/скрытие UI-поля.
