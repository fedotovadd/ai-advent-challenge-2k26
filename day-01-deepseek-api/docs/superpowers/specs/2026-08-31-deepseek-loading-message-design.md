# Сообщение об ожидании ответа DeepSeek

## Цель

Показывать пользователю, что программа продолжает работать, пока синхронный API-запрос к DeepSeek выполняется.

## Поведение

Непосредственно перед вызовом `client.chat.completions.create(...)` программа печатает в stdout строку `Ожидаем ответ DeepSeek...` с параметром `flush=True`. Благодаря немедленной очистке буфера сообщение появляется до получения ответа.

После завершения запроса ответ выводится существующим способом под заголовком `Ответ DeepSeek:`. При ошибке API сообщение ожидания остаётся в stdout, а описание ошибки выводится в stderr.

## Изменения

- `main.py` — добавить один вызов `print` перед API-запросом.
- `tests/test_main.py` — проверить, что сообщение уже записано в stdout к моменту начала API-вызова, вызов `print` содержит `flush=True`, а при ошибке API сообщение также остаётся видимым.
- `README.md` — упомянуть, что во время ожидания программа показывает статус.

## Ограничения

Анимация, потоки, перезапись строки терминала и дополнительные библиотеки не используются.
