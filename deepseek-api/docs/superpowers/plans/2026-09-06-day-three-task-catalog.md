# День 3: каталог задач Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить произвольную задачу в лаборатории «День 3» тремя встроенными задачами с независимыми эталонами и критериями; сохранять результаты каждой задачи до перезагрузки страницы.

**Architecture:** `main.py` получит неизменяемый серверный каталог, в котором каждая задача имеет идентификатор, название, текст, эталон и критерии. Маршрут примет только `taskId`, подставит данные из каталога в четыре стратегии и в запрос AI-сравнения. Клиент покажет `<select>` задач, будет хранить результаты в объекте по идентификатору и отрисовывать только активный результат.

**Tech Stack:** Python 3, `http.server`, встроенные HTML/CSS/JavaScript, `unittest`, OpenAI-совместимый DeepSeek API.
