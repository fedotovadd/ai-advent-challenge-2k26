# Логическое разбиение `main.py`

## Цель

Разделить обязанности большого файла `main.py` на небольшие модули без изменения HTTP API, пользовательского интерфейса, настроек агентов или поведения эксперимента Дня 3.

## Выбранный вариант

Выбран модульный разнос внутри `deepseek-api`, а не переход на веб-фреймворк и не частичное деление на произвольные утилиты. Он не добавляет зависимостей и сохраняет существующий способ запуска `python3 main.py`.

| Модуль | Ответственность |
| --- | --- |
| `agent.py` | Единственный источник констант чата; состояние агента, настройки, история, метаданные и расчёт стоимости. |
| `errors.py` | Общее исключение `MissingApiKeyError`, не связывающее доменный слой с провайдером. |
| `providers.py` | Выбор провайдера по модели и один вызов совместимого OpenAI API. |
| `day_three.py` | Каталог задач, промпты и синхронный/потоковый эксперимент четырёх стратегий. |
| `page.py` | Константа `PAGE` с HTML, CSS и JavaScript браузерного интерфейса. |
| `web.py` | HTTP-обработчик, валидация запросов, JSON/HTML-ответы и `ChatServer`. |
| `main.py` | Совместимые реэкспорты, `create_server()` и запуск приложения. |

## Совместимость и поток данных

`web.py` получает `ask_model` при создании сервера, создаёт общий `AgentRegistry` и передаёт его агентам. Для эксперимента Дня 3 обработчик вызывает функции из `day_three.py` с этой же функцией модели. `page.py` не зависит от Python-логики и передаётся обработчиком как готовая HTML-страница.

`agent.py` остаётся единственным источником `MODEL`, `MODELS`, `SYSTEM_PROMPT`, `DEFAULT_*` и связанных с чатом помощников. Их импортируют `web.py` и `day_three.py`; копии констант не создаются. `main.py` реэкспортирует все ранее доступные тестам константы эксперимента (`MODEL`, `SYSTEM_PROMPT`, `DAY_THREE_TASKS`, все системные промпты), `MissingApiKeyError` и `ask_deepseek`. Маршруты, форматы JSON, статусы, тела ответов и заголовки остаются прежними.

Внутренний импорт `OpenAI` переедет в `providers.py`, поэтому тест провайдера будет намеренно исправлен с `patch("main.OpenAI")` на `patch("providers.OpenAI")`. Это единственный тестовый seam, который меняет расположение; внешний контракт `main.ask_deepseek` сохраняется.

## Проверка

Тесты дополняются проверками, что модули можно импортировать отдельно, а `main.py` сохраняет прежний публичный интерфейс. Полный набор интеграционных тестов подтверждает прежние статусы, тела и заголовки HTTP-ответов, строгую валидацию `Content-Length`/`Transfer-Encoding`, NDJSON-поток `/api/day-03/stream`, а также доступность `server.registry` и `server.ask_model`. Затем запускаются unit-тесты агента и полный набор интеграционных HTTP-тестов. Синтаксис всех новых и изменённых Python-файлов проверяется компиляцией.

## Не входит в объём

Не меняются UI, модельные промпты, API-маршруты, форматы данных, список зависимостей и запуск приложения. Статические файлы не выносятся в отдельный веб-сервер.
