# День 5: модель и метаданные чата

## Цель

Добавить в локальный чат выбор модели и отображение параметров последнего ответа. При смене чата правая панель всегда показывает настройки и метаданные именно выбранной сессии.

## Решение

Каждая сессия хранит:

- `settings.model` — одну из трёх доступных моделей: `deepseek-v4-flash`, `glm-4.7-flash` или `deepseek-v4-pro`;
- `metadata` — данные последнего завершённого запроса этой сессии.

Клиент загружает обе структуры из активной сессии. При изменении модели он сохраняет настройки активной сессии. При отправке сервер использует модель из её настроек и после ответа сохраняет сформированные метаданные в ней же.

## Метаданные

Показываются:

- время ответа в секундах;
- суммарное число токенов;
- стоимость в долларах США.

Время измеряется вокруг вызова API. Токены берутся из поля `usage` ответа. Стоимость рассчитывается из входных и выходных токенов по таблице цен, заданной в коде. Если API не возвращает usage, значение выводится как «—».

## Границы прототипа

Без постоянного хранилища, исторической аналитики, сравнения моделей и расширенных расчётов тарифов. Проверка ограничивается существующим набором тестов с несколькими целевыми сценариями для новой серверной модели данных.
