# Настройка температуры ответа — дизайн

## Цель

Дать пользователю возможность задавать температуру для каждого запроса к DeepSeek из веб-интерфейса. Значение должно передаваться провайдеру в параметре `temperature`.

## Интерфейс

В правой панели добавить карточку «Настройки ответа». В ней разместить ползунок температуры:

- допустимый диапазон: от `0` до `2`;
- шаг: `0.1`;
- начальное значение: `1`;
- рядом с ползунком отображается текущее число.

Значение принадлежит интерфейсу, а не отдельной сессии: выбранная температура применяется к следующему сообщению в любой открытой сессии.

## Передача данных

При отправке сообщения браузер включает `temperature` в JSON тела запроса вместе с `text`. Сервер принимает только числовое значение в диапазоне `0`–`2`, добавляет его в сформированный payload и передаёт его в DeepSeek API.

Раздел «Отправлено в API» продолжает показывать точный payload, поэтому пользователь может проверить выбранную температуру.

## Ошибки и совместимость

Если `temperature` отсутствует, сервер использует значение по умолчанию `1`, чтобы существующие клиенты продолжали работать. Нечисловые, бесконечные либо выходящие за диапазон значения возвращают `400` с понятной ошибкой; запрос к модели при этом не выполняется.

## Проверка

Автотесты должны подтверждать, что значения `0`, `0.7` и `1.2` доходят до модели в поле `temperature`, отражаются в метаданных и что сервер отклоняет некорректные значения.
