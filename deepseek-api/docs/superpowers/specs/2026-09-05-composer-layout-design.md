# Закреплённое поле сообщения и упрощение настроек — дизайн

## Цель

Сделать поле отправки сообщения постоянно видимым в нижней части центральной панели и убрать неиспользуемую настройку «Инструкция свободного формата».

## Интерфейс

- Центральная область чата занимает высоту окна. Шапка и область создания сообщения не сжимаются, а прокручивается только история сообщений между ними.
- Поле сообщения с кнопкой «Отправить» остаётся у нижней границы окна при длинной переписке.
- В правой панели остаются System prompt, формат ответа, максимум токенов, стоп-последовательность и метаданные.
- Блок «Инструкция свободного формата» удаляется полностью.

## Данные и API

- `formatInstruction` удаляется из настроек сессии по умолчанию, валидации API и клиентского объекта настроек.
- При обычном тексте и JSON используется только редактируемый System prompt. Режим JSON по-прежнему передаёт `response_format={"type":"json_object"}`.
- Логика `max_tokens`, включая текущую обработку ответа модели, в рамках этой работы не изменяется.

## Ошибки и проверки

- Автосохранение остальных настроек сохраняется: формат — сразу, остальные поля — после короткой паузы.
- Тесты подтверждают отсутствие удалённого поля и ключа из настроек, а также структуру разметки, которая оставляет область создания сообщения видимой при прокрутке истории.
