# День 27 — локальная LLM в веб-чате: результаты

Проверено 7 октября 2026 года (МСК). Модель `qwen2.5:1.5b`, Ollama `0.35.1`. Временный экземпляр веб-чата работал на `http://127.0.0.1:8765` с состоянием `/private/tmp/day27-live-agents.json`; облачные ключи удалены из окружения процесса.

## Подготовка

```bash
ollama list
ollama show qwen2.5:1.5b
curl --max-time 5 -fsS http://127.0.0.1:11434/api/tags
env -u DEEPSEEK_API_KEY -u ZAI_API_KEY ./.venv/bin/python -u -c 'from pathlib import Path; from main import create_server; server=create_server(port=8765, state_path=Path("/private/tmp/day27-live-agents.json")); server.serve_forever()'
```

`ollama list` и `/api/tags` показали `qwen2.5:1.5b` (`65ec06548149`, 986 MB, capability `completion`). `ollama show` сообщил длину контекста модели 32768; приложение применяет консервативный учебный лимит 4096.

## Проверка в браузере

В настройках агента выбрано «Локально · qwen2.5:1.5b». В заголовке и списке агентов появилось `qwen2.5:1.5b`. Снимок настроек: `format=text`, `maxTokens=null`, `contextStrategy=sliding_window`, `windowSize=10`, `temperature=1`. В метаданных фактических запросов присутствовало `max_tokens: 512`; стоимость показывалась как «Бесплатно» с пояснением об отсутствии оплаты облачного API.

| Ход | Сообщение пользователя | Ответ в ленте | Статус / токены |
|---|---|---|---|
| 1 | «Запомни слово маяк и ответь одним словом: какое слово ты запомнил?» | `Mayок.` | `200 OK`, 148 вход / 4 выход |
| 2 | «Какое слово я попросил запомнить? Ответь по-русски одним словом.» | `Маяк` | `200 OK`, 184 вход / 4 выход |

Метаданные второго запроса содержали предыдущие `user` и `assistant` реплики, затем новый вопрос. Первый ответ смешал латиницу и кириллицу; это фактический текст компактной модели. Оба ответа появились в обычной ленте чата.

Маршрут генерации: `providers.ask_model` для точного имени `qwen2.5:1.5b` создаёт SDK-клиент с `base_url=http://127.0.0.1:11434/v1/`, `api_key=ollama`, `timeout=120`, `max_retries=0`. Это проверено тестом с подменённым `OpenAI`, включая запрет чтения облачных ключей. Живой веб-чат получил ответы при удалённых `DEEPSEEK_API_KEY` и `ZAI_API_KEY`; облачного fallback в коде нет. Отключение внешнего интернета отдельно не выполнялось.

## Отказ и восстановление

```bash
brew services stop ollama
brew services start ollama
curl --max-time 5 -fsS http://127.0.0.1:11434/api/tags
```

После остановки сервиса в браузере отправлено «Проверка недоступности локального сервиса». Чат показал: «Локальный сервис Ollama недоступен. Запустите Ollama и повторите запрос.» В истории осталось сообщение пользователя без ответа ассистента; статус метаданных — «Ошибка API», счётчик успешных вызовов не увеличился. Автоматического перехода к облаку не было.

После запуска Ollama `/api/tags` снова показал модель. Следующее сообщение «Сервис снова работает? Ответь одним словом: да.» получило ответ `да` со статусом `200 OK`. Предыдущий неотвеченный запрос остался в истории как отдельное сообщение пользователя.

- `python -m unittest discover -s tests -p test_local_model_agent.py -q`: 5 тестов, OK.

- `python -m unittest discover -s tests -v`: 421 тест за 48,694 с, OK.

После демонстрации временный веб-сервер остановлен и его файл состояния удалён. Ollama восстановлена как сервис Homebrew.
