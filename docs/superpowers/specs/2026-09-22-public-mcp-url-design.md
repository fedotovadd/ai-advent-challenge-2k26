# Подключение публичного MCP по URL — дизайн

## Цель

Расширить вкладку MCP: пользователь вводит URL публичного MCP-сервера по
HTTPS, нажимает «Подключить» и получает список его инструментов. Открытие
вкладки ничего не подключает. Инструменты по-прежнему не передаются DeepSeek
и не вызываются из чата.

## Границы

- Поддерживаются только удалённые Streamable HTTP MCP-серверы с `https://`.
- `http://`, IP-адреса и `localhost` не поддерживаются. Имена доменов
  пользователь вводит осознанно; отдельный сетевой прокси для защиты от
  подмены DNS не входит в локальное учебное приложение.
- URL, инструменты и состояние подключения не сохраняются между запусками.
- OAuth, API-ключи, локальный `stdio` и вызовы MCP-инструментов не входят в
  эту задачу.

## Поток данных

На вкладке MCP находится поле URL с DeepWiki как примером и кнопка
«Подключить». По нажатию `mcp-controls.js` отправляет
`POST /api/mcp/tools` с JSON `{"url": "..."}`. `web.py` проверяет
same-origin, размер тела до 4 KiB и точную схему тела, затем передаёт URL в
`mcp_client.list_tools(url)`.

Клиент проверяет абсолютный HTTPS URL без учётных данных, query и fragment;
IP-литералы и имя `localhost` отклоняются. URL является явным действием
пользователя локального приложения: браузер не может инициировать этот
same-origin запрос с другого сайта. Затем клиент создаёт MCP Streamable
HTTP-сессию, выполняет инициализацию и `list_tools()` с общим тайм-аутом 10
секунд на весь цикл инициализации и получения списка. Ответ ограничивается
первыми 100 инструментами; имя ограничивается 200 символами, описание —
1 000, и содержит только эти два поля. Отсутствующее, пустое или нестроковое
описание становится «Описание не предоставлено». Любой HTTP-редирект
запрещён. Ошибка URL возвращается как 400, ошибка подключения или протокола
— как 502; технические детали остаются в консоли локального сервера.

Успешный ответ API имеет вид
`{"serverUrl": "https://...", "tools": [{"name": "...", "description": "..."}]}`.
Ответы 400 и 502 имеют единственное поле `{"error": "сообщение"}`.

## Интерфейс

Пока идёт запрос, кнопка отключена и показывает «Подключение…». После успеха
видны статус «Подключение установлено», количество и до 100 карточек
инструментов. Ошибки выводятся в том же статусе без технической трассировки.
Текст от сервера вставляется только через `textContent`.

## Проверка

Unit-тесты покрывают валидацию URL, последовательность MCP
initialize/list_tools и описание по умолчанию. HTTP-тесты покрывают
успешное подключение с внедрённым клиентом, 400, 502 и same-origin. UI-тесты
проверяют поле URL, передачу JSON только по кнопке и безопасный рендеринг.
Ручная проверка выполняется с DeepWiki и подтверждает непустой список
инструментов.
