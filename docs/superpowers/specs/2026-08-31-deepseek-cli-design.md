# Минимальный CLI-клиент DeepSeek

## Цель

Создать учебный пример на Python, который принимает текст пользователя, отправляет его в DeepSeek через API и выводит ответ модели в консоль.

## Состав проекта

- `main.py` — вся логика приложения.
- `requirements.txt` — единственная зависимость `openai`.
- `README.md` — получение API-ключа, установка зависимости и запуск.

## Архитектура и поток данных

Программа читает `DEEPSEEK_API_KEY` из переменной окружения. Если ключ отсутствует, она завершает работу с понятной инструкцией. Затем программа получает запрос через `input()`, создаёт клиент OpenAI с базовым URL `https://api.deepseek.com`, вызывает Chat Completions API с моделью `deepseek-v4-flash` и печатает `response.choices[0].message.content`.

Ключ не хранится в исходном коде или файлах проекта.

## Обработка ошибок

- Отсутствующий API-ключ: понятное сообщение с названием нужной переменной окружения.
- Пустой запрос: понятное сообщение без отправки API-запроса.
- Ошибка API или сети: короткое сообщение с причиной; необработанный traceback пользователю не показывается.

## Проверка

- Скомпилировать `main.py` встроенным модулем `py_compile`.
- Запустить программу без ключа и убедиться, что она выводит ожидаемую инструкцию.
- Реальный сетевой вызов выполнить после создания ключа DeepSeek и пополнения доступного API-баланса, если это потребуется аккаунту.

## Вне области задачи

Веб-интерфейс, история диалога, потоковая выдача, `.env`, база данных и сложная конфигурация не требуются.
