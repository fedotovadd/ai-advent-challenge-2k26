# День 16 — вкладка MCP: дизайн

## Цель

Добавить в локальный веб-чат отдельную вкладку «MCP», в которой пользователь
подключается к проверенному публичному MCP-серверу DeepWiki и видит
объявленные им инструменты. На этом этапе DeepSeek не получает инструменты и
не вызывает их.

## Границы

- Используется официальный Python MCP SDK 1.30+ (линейка 1.x) и транспорт
  Streamable HTTP; требуется Python 3.10 или новее.
- Используется только открытый сервер DeepWiki `https://mcp.deepwiki.com/mcp`;
  выбор произвольного URL и список других серверов не входят в День 16.
- Вкладка показывает только имя и описание каждого инструмента.
- Подключение и список инструментов не сохраняются в истории агентов;
  это экран диагностики текущего запуска.
- Поддержка ключей, OAuth, вызов инструментов и передача их в DeepSeek не
  входят в День 16.

## Архитектура и поток данных

`static/mcp-controls.js` создаёт содержимое вкладки и по нажатию кнопки
отправляет `POST /api/mcp/tools` без пользовательского URL. Маршрут в `web.py`
вызывает небольшую функцию из нового `mcp_client.py` только с константным
адресом DeepWiki.

Клиент открывает Streamable HTTP-сессию MCP через SDK, завершает протокольную
инициализацию и запрашивает `list_tools()` с тайм-аутом 10 секунд. Он
возвращает только безопасные для интерфейса поля `name` и `description`;
отсутствующее описание отображается как «Описание не предоставлено».
Обработчик HTTP превращает ошибки соединения и протокола в понятный
JSON-ответ, а браузер выводит его в статусе вкладки.

## Компоненты

- `mcp_client.py` — изолированный адаптер MCP: константный адрес DeepWiki,
  подключение и преобразование ответа SDK в простые словари.
- `web.py` — маршрут API и ограничение размера тела; клиент передаётся
  `ChatServer` как зависимость, чтобы тесты не обращались к интернету.
- `static/mcp-controls.js` — разметка, запрос, отображение состояний и
  инструментов.
- `static/index.html` — пункт навигации, контейнер вкладки, подключение
  скрипта и минимальные стили.

## Ошибки и безопасность

Адрес MCP не принимается от браузера: сервер использует проверенный
константный HTTPS endpoint DeepWiki. SDK допускает только редирект 307/308 в
пределах исходной схемы, хоста и порта; переход на другой origin не
допускается. Проблема соединения или протокола даёт `502`.
Сервер не перенаправляет браузер к MCP напрямую, поэтому тот не сталкивается
с CORS и не получает данные подключения.

## Проверка

Unit-тесты докажут использование константного endpoint и извлечение
имени/описания инструментов. HTTP-тесты проверят успешный маршрут с
внедрённым клиентом, отсутствие принимаемых параметров, ошибку соединения и
same-origin.
Отдельная ручная проверка с DeepWiki подтвердит настоящее соединение и
непустой список инструментов.
