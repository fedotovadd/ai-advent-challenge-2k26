# Day 10 Context Strategies Implementation Plan

**Goal:** Четыре стратегии (Summary сохранён по уточнению пользователя), переключатель, независимые ветки и воспроизводимое сравнение.
**Architecture:** context_memory.py отвечает за ограниченные facts и проверку состояния.
Agent собирает payload, обрезает окно, управляет копиями checkpoint и веток.
Web предоставляет маршруты, отдельный context-controls.js расширяет интерфейс.
**Tech Stack:** Python, unittest, стандартный HTTP server, JavaScript, существующий API client.
